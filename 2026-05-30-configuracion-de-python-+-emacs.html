Configuracion de python + emacs

Instalación de herramientas Python con pipx

Debian/Ubuntu usan PEP 668 (externally-managed-environment). No se puede instalar paquetes globales con pip directamente. La solución oficial es usar pipx.

Instalar pipx

sudo apt install pipx
pipx ensurepath
# Cerrar y abrir la terminal, o ejecutar:
source ~/.bashrc

Instalar herramientas del curso

Cada herramienta se instala en su propio entorno virtual aislado: 

pipx install python-lsp-server[all]
pipx install ruff
pipx install pytest
pipx install ipython
pipx install mypy
Paquete Propósito
python-lsp-server[all] Servidor LSP (autocompletado, linting)
ruff Linter + formatter ultrarrápido
pytest Testing
ipython REPL interactivo mejorado
mypy Type checking (opcional)

Entorno virtual para proyectos del curso

Se crea un venv por proyecto dentro del propio directorio: 

mkdir -p ~/projects/curso-python
cd ~/projects/curso-python
python3.11 -m venv .venv
echo ".venv" >> .gitignore

Para activarlo manualmente: 

source .venv/bin/activate

Los paquetes propios del proyecto (no herramientas) se instalan así: 

pip install numpy pandas requests  # ejemplo

Configuración de Emacs

Se añade al archivo /home/martin/.emacs.d/init.el.

Python mode (uso del built-in)

Emacs 30 incluye python.el de serie. Se configura así: 

;; Python
;; ======
(use-package python
  :delight
  :custom
  (python-shell-interpreter "python3.11")
  (python-shell-interpreter-args "-i")
  :hook (python-mode . eglot-ensure)
  :config
  ;; Ejecutar buffer con C-c C-c
  (define-key python-mode-map (kbd "C-c C-c") 'python-shell-send-buffer)
  ;; Enviar región seleccionada
  (define-key python-mode-map (kbd "C-c C-r") 'python-shell-send-region)
  ;; Abrir/ir al REPL
  (define-key python-mode-map (kbd "C-c C-z") 'python-shell-switch-to-shell)
  ;; Evaluar expresión antes del punto
  (define-key python-mode-map (kbd "C-c C-e") 'python-shell-send-statement))

Ruff: linter + formatter al guardar

;; Ruff (formateo automático al guardar)
(use-package ruff-format
  :ensure t
  :hook (python-mode . ruff-format-on-save-mode))

Virtualenv automático con pyvenv

;; Virtualenv automático
(use-package pyvenv
  :ensure t
  :config
  (setq pyvenv-mode t)
  ;; Activar .venv automáticamente al abrir archivos en el proyecto
  (setq pyvenv-work-on-project-mode t))

requirements.txt

;; requirements.txt
(use-package pip-requirements
  :ensure t
  :mode ("requirements\\.txt\\'" . pip-requirements-mode))

Eglot (LSP) — vincular pylsp con Python

Buscar el bloque de eglot existente en init.el (ya debe haber uno para TypeScript/Rust) y añadir la entrada de Python: 

(add-to-list 'eglot-server-programs
             '(python-mode . ("pylsp")))

Dired — mostrar .venv oculto por defecto (opcional)

Para que Dired no muestre el directorio .venv a menos que se pida explícitamente: 

(with-eval-after-load 'dired
  (add-to-list 'dired-omit-extensions ".venv")
  (setq dired-omit-files (concat dired-omit-files "\\|^.venv$"))
  (add-hook 'dired-mode-hook 'dired-omit-mode))

Verificación de la configuración

Al abrir hola.py en Emacs debe ocurrir:

  1. pyvenv activa .venv automáticamente (se ve en el mode-line, si doom-modeline está configurado)
  2. eglot se inicia (se puede verificar con M-x eglot)
  3. ruff-format formatea al guardar (C-x C-s)
  4. C-c C-c ejecuta el buffer de Python

Para comprobar que todo funciona: 

echo 'print("Hola, mundo!")' > ~/projects/curso-python/hola.py
echo 'import sys
print(sys.version)

def suma(a, b):
    return a + b

assert suma(2, 3) == 5
print("Prueba OK")' > ~/projects/curso-python/test_hola.py

Luego abrir hola.py en Emacs y probar las teclas rápidas.

Resumen de teclas rápidas en Python

Atajo Acción
C-c C-c Ejecutar buffer completo
C-c C-r Ejecutar región seleccionada
C-c C-z Ir al REPL de Python
C-c C-e Evaluar expresión actual
C-x C-s Guardar (activa ruff-format)
M-. Ir a definición (eglot)
M-? Referencias (eglot)
C-c C-q Formatear con ruff (manual)

Notas adicionales

  • Si se quiere usar black en lugar de ruff para formatear, instalar black con pipx y usar el paquete Emacs blacken en vez de ruff-format.
  • Para debugging: pipx install pdbpp para un pdb mejorado.
  • Si el proyecto necesita numpy, pandas, etc., se instalan dentro del .venv del proyecto con pip install.
