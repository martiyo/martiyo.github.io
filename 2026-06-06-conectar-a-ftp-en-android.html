Conectar-a-ftp-en-Android

Conectarse al servidor ftp de android desde la terminal.

Servidor FTP en Android

Datos de conexión

  • Host: 192.168.x.x
  • Puerto: x
  • Usuario/Pass: (el que hayas configurado)

Subir archivos

Interactivo (ftp)

ftp 192.168.1.206 3721
  put archivo.txt          # subir un archivo
  put /ruta/local/archivo.zip    # subir desde ruta específica
  mput *.jpg               # subir múltiples archivos
  bye                      # salir

Una línea (curl)

curl -T archivo.txt ftp://192.168.1.206:3721/ --user usuario:contraseña
curl -T archivo.txt ftp://192.168.1.206:3721/ --user anonymous:

Descargar archivos

Interactivo (ftp)

ftp 192.168.1.206 3721
  get archivo.txt                  # descargar un archivo
  get archivo.zip /ruta/local/     # descargar a ruta específica
  mget *.jpg                       # descargar múltiples archivos
  prompt                           # desactivar confirmación en mget/mput
  bye

Una línea (curl)

curl -O ftp://192.168.1.206:3721/archivo.txt --user usuario:contraseña
curl -o /ruta/local/archivo.txt ftp://192.168.1.206:3721/archivo.txt --user usuario:contraseña

Descarga recursiva (wget)

wget -r ftp://usuario:contraseña@192.168.1.206:3721/

Notas

  • El puerto y host dependen de la app FTP en Android
  • Para modo anónimo, usuario = anonymous, contraseña = vacía o email
