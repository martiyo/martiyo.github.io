Eglot - El cliente LSP para Emacs

Eglot (Emacs Polyglot) es un cliente LSP (Language Server Protocol) minimalista para Emacs. A diferencia de lsp-mode, Eglot está diseñado para ser simple, usar las APIs nativas de Emacs y requerir configuración cero en la mayoría de los casos.

¿Qué es LSP?

El Language Server Protocol es un estándar que permite a los editores de código comunicarse con servidores que proveen funcionalidades como autocompletado, ir a definición, diagnósticos, etc. Cada lenguaje tiene su propio servidor LSP (pylsp para Python, typescript-language-server para JS/TS, rust-analyzer para Rust, etc.) y Eglot actúa como puente entre Emacs y esos servidores.

Características principales

Eglot aprovecha las herramientas nativas de Emacs en lugar de reemplazarlas:

Característica Mecanismo Emacs Atajo común
Autocompletado completion-at-point / Corfu (automático)
Diagnósticos Flymake (en línea)
Ir a definición xref-find-definitions M-.
Volver de definición xref-pop-marker-stack M-,
Buscar referencias xref-find-references M-?
Documentación al vuelo ElDoc (en echo area)
Documentación detallada eldoc-doc-buffer C-h .
Formatear código eglot-format / eglot-format-buffer (según config)
Renombrar símbolo eglot-rename C-x n n
Code actions eglot-code-actions C-c C-a
Ejecutar acción rápida eglot-code-action-quickfix C-c C-q
Hover (información) eglot-help-at-point C-c C-d

Instalación

Eglot viene incluido con Emacs 29+. Solo hay que asegurarse de tenerlo cargado: 

(use-package eglot
  :ensure t
  :defer t
  :hook (python-mode . eglot-ensure)
  :config
  ;; Asociar servidores LSP con sus modos
  (add-to-list 'eglot-server-programs
               '(python-mode . ("pylsp")))
  (add-to-list 'eglot-server-programs
               '((web-mode js-mode typescript-mode) "typescript-language-server" "--stdio"))
  (add-to-list 'eglot-server-programs
               '(rust-mode . ("rust-analyzer"))))

eglot-ensure en el hook hace que Eglot se active automáticamente al abrir archivos de ese modo.

Configuración del servidor

Cada servidor LSP tiene sus propias opciones. Se configuran a través de eglot-workspace-configuration, que es un plist que Eglot envía al servidor al iniciar: 

(setq-default eglot-workspace-configuration
  '(:pylsp (:plugins (:black (:enabled t :line_length 120)
                       :autopep8 (:enabled nil)
                       :yapf (:enabled nil)
                       :pycodestyle (:enabled t :maxLineLength 120)))))

Configuración para Python

Instalar el servidor LSP

El servidor para Python es pylsp (python-lsp-server). Se instala con pipx para mantenerlo aislado del sistema: 

pipx install python-lsp-server[all]
pipx install python-lsp-black  # plugin para formatear con Black
pipx install ruff              # linter rápido (opcional)

Los argumentos [all] instalan todos los plugins incluidos por defecto. Si se quiere minimizar, se puede instalar solo el base y agregar plugins manualmente: 

pipx install python-lsp-server
pipx inject python-lsp-server pylsp-rope  # refactorings

Configurar formateo al guardar

Para que Emacs formatee automáticamente con Black al guardar, se agrega un hook local al buffer de Python: 

(use-package python
  :delight
  :custom
  (python-shell-interpreter "python3.11")
  :hook ((python-mode . eglot-ensure)
         (python-mode . (lambda ()
                          (add-hook 'before-save-hook
                                    (lambda () (eglot-format))
                                    nil 'local))))
  :config
  (define-key python-mode-map (kbd "C-c C-c") 'python-shell-send-buffer)
  (define-key python-mode-map (kbd "C-c C-r") 'python-shell-send-region)
  (define-key python-mode-map (kbd "C-c C-z") 'python-shell-switch-to-shell)
  (define-key python-mode-map (kbd "C-c C-e") 'python-shell-send-statement))

El truco está en nil 'local en add-hook: agrega el formateo solo al buffer actual de Python, no a todos los buffers.

Ajustar el límite de línea

pycodestyle (incluido en pylsp) usa 79 caracteres por defecto. Para cambiarlo a 120, crear setup.cfg en la raíz del proyecto: 

[pycodestyle]
max-line-length = 120

Esto afecta tanto a pylsp como a cualquier herramienta externa que lea setup.cfg. La misma configuración también se puede pasar por eglot-workspace-configuration como se mostró antes.

Virtualenv automático

Al trabajar con proyectos Python que usan .venv, es útil activarlo automáticamente con pyvenv: 

(use-package pyvenv
  :ensure t
  :config
  (setq pyvenv-mode t)
  (setq pyvenv-work-on-project-mode t))

Al abrir un archivo dentro de un proyecto que tiene .venv, se activa automáticamente y pylsp usa los paquetes instalados en ese entorno.

Desactivar plugins de pylsp no deseados

Por defecto pylsp activa varios plugins. Se pueden desactivar los que no se usen para hacerlo más rápido: 

(setq-default eglot-workspace-configuration
  '(:pylsp (:plugins
            (:black (:enabled t :line_length 120)
             :autopep8 (:enabled nil)
             :yapf (:enabled nil)
             :mccabe (:enabled nil)
             :pyflakes (:enabled nil)
             :pycodestyle (:enabled t :maxLineLength 120)
             :pydocstyle (:enabled nil)
             :pylint (:enabled nil)
             :rope (:enabled nil)))))

Configuración para JavaScript / TypeScript

Instalar el servidor LSP

npm install -g typescript typescript-language-server

Configuración en init.el

(add-to-list 'eglot-server-programs
             '((web-mode js-mode typescript-mode) "typescript-language-server" "--stdio"))

Asegurarse de que el binario está en el PATH: 

(setenv "PATH" (mapconcat 'identity exec-path path-separator))
(setq exec-path (append exec-path '("/usr/bin/typescript-language-server")))

tsconfig.json / jsconfig.json

El servidor TypeScript lee la configuración del proyecto desde tsconfig.json (TypeScript) o jsconfig.json (JavaScript puro). Ejemplo: 

{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "*": ["src/*"]
    }
  }
}

Solución de problemas

pylsp no arranca / "terminated (killed)"

Causa más común: falta el plugin python-lsp-black y está habilitado :black (:enabled t).

Solución: 

pipx install python-lsp-black

O deshabilitar Black temporalmente en eglot-workspace-configuration.

Eglot no se activa automáticamente

Verificar que eglot-ensure está en el hook correcto: 

:hook (python-mode . eglot-ensure)

Si se usa M-x eglot manualmente y funciona, el problema está en el hook.

Formateo al guardar no funciona

Verificar que el hook está bien configurado: 

(lambda () (add-hook 'before-save-hook (lambda () (eglot-format)) nil 'local))

El 'local es clave: sin él, el formateo se aplicaría a todos los buffers.

También verificar que eglot-format existe (debe estar en el built-in de Emacs 30+): 

M-x describe-function RET eglot-format RET
